Event Lottery App: Team-Based Android Development

Android · Java · Agile · GitHub Collaboration

Overview

The Event Lottery App is a full-featured Android application built by a six-person team as part of a software engineering course project. The goal was to create a fair and accessible event registration system using a lottery-based waitlist instead of first-come-first-served signups.

The platform supports Entrant, Organizer, and Admin roles and is backed by Firebase for real-time data synchronization. From the start, the project emphasized collaborative development practices and incremental delivery.

My Role

I primarily worked on the Admin workflows, taking ownership of platform-wide moderation features such as managing events, profiles, uploaded images, and notification logs.

I chose this role based on my prior experience building role-based systems in a full-stack web application (Next Up Hoops), where I implemented admin dashboards and permission-controlled views. That experience translated well to designing similar responsibilities in a mobile environment.

I also contributed to parts of the Organizer workflows and helped with unit and UI testing to ensure correct role-based behavior.

Teamwork & Process

Our team followed Agile and Scrum practices throughout the project. We maintained a product backlog, broke requirements into user stories, and planned weekly sprints.

All development was managed through GitHub using issues, feature branches, pull requests, code reviews, and merge conflict resolution.
