AI Resume Skill Gap Analyzer

Applied NLP system for resume analysis and personalized upskilling insights

Links: GitHub Repository

Overview

The AI Resume Skill Gap Analyzer is a project I built to explore how modern NLP and AI tools can be used to analyze resumes in a more meaningful way than simple keyword matching.

Given a resume and a job description, the system identifies missing or weak skills and generates personalized recommendations for how a candidate could close those gaps.

How It Works

Resumes and job descriptions are first parsed and normalized to extract relevant text and skills. I then generate semantic embeddings using Sentence-BERT to compare skills based on meaning rather than exact wording.

Based on these similarities, the system identifies skill gaps relative to predefined role benchmarks. An OpenAI-powered recommendation module then generates tailored learning suggestions, certifications, and next steps for improvement.

Interpreting the Skill Match Results

One of the main outputs of the system is a percentage-based match score that shows how well a resume aligns with a specific role. In this example, the resume is evaluated against a Data Scientist benchmark.

Each job-required skill is embedded using Sentence-BERT and compared against all skills extracted from the resume using cosine similarity. The system selects the closest matching resume skill and records the similarity score.

Exact matches (such as Python → Python or SQL → SQL) result in a 100% score. Partial or related matches (for example, Pandas → Python) produce lower similarity scores, indicating conceptual overlap rather than direct experience.

A skill is only counted toward the final match score if it exceeds a predefined similarity threshold. The overall percentage represents the proportion of required role skills that are sufficiently covered, while skills below the threshold are listed as missing to avoid inflated results.

Key Features

  • Semantic skill matching using Sentence-BERT embeddings
  • Role-based skill benchmarking using a curated taxonomy
  • AI-generated upskilling and learning recommendations
  • Modular FastAPI backend with clear separation of concerns
  • Containerized deployment with Docker
