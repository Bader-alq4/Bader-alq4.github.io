Event Lottery App

Android event management platform with lottery-based registration

Links: GitHub Repository

Overview

The Event Lottery App is a full-featured Android application built as part of a team-based software engineering project. Its primary goal is to make event registration fair and accessible by replacing traditional first-come-first-served signups with a lottery-based waitlist system.

The platform supports three user roles: Entrants, Organizers, and Administrators. The application is cloud-native and backed by Firebase, that allows real-time updates across all users.

This project strongly emphasized collaborative development practices, including Agile planning, GitHub-based workflows, and delivery across multiple sprints.

Key Features

  • Lottery-based event registration with waitlists and invitations
  • Role-based flows for Entrants, Organizers, and Admins
  • Passwordless device-based authentication
  • QR code scanning for event discovery and check-in
  • Real-time notifications and event updates
  • Geolocation and map-based visualization of entrants

App Walkthrough

Entrant Experience

Entrants can browse joinable events, view event details, join waitlists, and receive real-time notifications when selected in a lottery.

Organizer Tools

Organizers can create events, manage waitlists, run lottery selections, and view geographic distributions of entrants using integrated maps.

Admin Moderation

Administrators have full platform oversight, allowing them to moderate events, user profiles, and uploaded images.

Teamwork & Development Process

This project was developed by a six-person team following Agile and Scrum practices. We maintained a structured product backlog, planned weekly sprints, and tracked progress using GitHub Issues and Projects.

All features were implemented through feature branches and pull requests, with regular code reviews and merge conflict resolution.
